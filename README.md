Attached in this reposistory are three items: a README (what you're currently reading), a manual to guide users towards understanding how this code can be appropriately used (including examples), and a folder containing three modules; one general simulation for thermal propagation, one for temperature distribution affecting fish livelihood, and one for modeling optimal computer architecture by changing material geometries.

If you are lazy here are the general instructions of use:
1. Download and run whichever module you prefer. It will ask you to input n sides of a polygon, this determines the shape of your base plate.
2. The sim will load you to a screen where you can input static (temperature remains the same) and oscillating points (temperature varies over time). Regular left click --> static points. Hold command and left click (on mac) to input oscillating points. You can place as many points as you'd like to model whatever infrastructure you prefer. You can also change the oscillation parameters for your oscillating points.
3. When you run the software it might take some time depending on how many points you input/how stubborn your computer is. Feel free to grab a snack while you wait.
4. Once the simulation pops up in another tab you may run it and observe static modes versus oscillatory modes, as well as fish survival likelihood (depending on which module you ran), and ideal computer infrastructure optimization.

Enjoy!
